# 🌌 Luma Source Code Viewer

Luma is a lightweight web-based source code viewer that allows users to inspect websites, view HTML source, and extract CSS and JavaScript files in a DevTools-style interface.

---

## 🔥 Features
- View full HTML source of any website
- Extract CSS and JavaScript files
- Syntax highlighting (VS Code style)
- File explorer sidebar
- Search functionality
- Console UI (DevTools-like)
- Theme switching support
- Download source code

---

## 🚀 How to use
1. Open the app in your browser or Android WebView
2. Enter a website URL
3. Click "View"
4. Explore source, CSS, and JS files

---

## ⚠️ Notes
- Some websites may not load due to CORS restrictions
- This tool is for educational and development purposes only

---

## 📱 Android Version
Luma can also be packaged as an Android app using WebView-based tools like WebViewGold.
